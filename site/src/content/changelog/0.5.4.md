title: A detected Python virtualenv, and Run before on a Service
date: 2026-11-10
released: true
---

- **A detected Python virtualenv is applied for you.** When you add a Project, a Python command such as `uvicorn` or `flask` gets the nearest real `.venv`, `venv` or `virtualenv` attached, and the command stays clean. Edit Service and the import review show **Using detected virtualenv** (or the folder's name). localhost puts that environment first on `PATH` and sets `VIRTUAL_ENV` when the Service starts. You can point the field at another folder or turn it off. Commands that already use `uv`, Poetry or Pipenv, or that already name the venv's binary, are left as they are. Services you already have are not rewritten on a re-scan.
- **Run before, on a Service.** An optional command that runs in the same shell as the Service, before it. Use it for `nvm use`, `source .env.sh`, or anything else that should be in place first. If it fails, the Service does not start, and the log says so.
