localhost now runs on one Rust core shared by every client, and comes to Linux.

- **Linux**: one Tauri app with the same main window, editors, command palette and shortcuts, a tray menu and a Quit that asks first. Packaged as `.deb`, `.rpm` and AppImage.
- **One core**: Projects, Runs, logs, environment, Listeners and detection moved into a Rust core. The macOS app calls it in-process, so it behaves exactly as before.
- **Logs** stream to the Linux app in batches, into a virtualized view that stays smooth with very chatty Services.
- **The `localhost` command**, on the same core and data: `projects`, `status`, `logs` and `up`.
