- **`localhost mcp`**: a Model Context Protocol server for Cursor, Claude Code and other coding agents. They list Projects and Services, start and stop them (one Service or Start All), and read status, logs and ports, instead of starting dev servers in a shell you can't see. The Services an agent starts stop when it disconnects, unless the app is open, and it never starts a second copy of one a `localhost up` runs. See [Coding agents (MCP)](/docs/mcp).
- **The app and agents share their Services.** On macOS and Linux, the app and `localhost mcp` drive one localhost core in the background: a Service an agent starts is Running in the app, with its logs, and one you start in the app is running for the agent. A stop from either stops the same Run. When an agent disconnects, the Services it started keep running if the app is open. See [The background core](/docs/mcp#the-background-core).
- **An agent skill**, `skills/localhost-mcp/SKILL.md`, that teaches agents to use it: Services through localhost rather than a shell, `status` before saying anything runs, `logs` and `ports` when something fails.
