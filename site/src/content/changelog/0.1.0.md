The first version of localhost: a native SwiftUI app for macOS.

- **Projects and Services**: one command line, working directory and environment per Service, run in your login shell. Start, stop and restart one Service, or Start All / Stop All in dependency order.
- **Ports**: a Service is Running once its Port accepts connections. A taken port says who holds it, and a Service can move to the next free one for a Run. The Ports view lists every Listener on the machine.
- **Environment**: Project and Service variables, Environment Profiles and Secrets in the Keychain. “Restart to apply” when a running Service's configuration changes.
- **Logs**: each Service's output with colours, the merged All services view, filter and clear.
- **Suggestions**: Add Project scans the folder for Node scripts, Compose services, Python apps and Cargo binaries, for you to review.
- **Project files**: export a Project to YAML and import it again.
- **Keyboard and accessibility**: the ⌘K command palette, a shortcut for every action, VoiceOver, Reduce Motion and Reduce Transparency.
- **The menu bar companion**, and Orphans offered to stop after a crash.
