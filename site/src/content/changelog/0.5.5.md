date: 2026-11-13
released: false
---

- **A welcome on the first launch.** Three short steps explain the basics: a Project is a folder, a Service is a command that keeps running (like `pnpm dev` or `docker compose up`), and the port tells localhost it's up. The last step ends in **Add Project…**, which opens the usual scan and Suggestions review. You can skip it at any step, and once it's seen or skipped it never opens again.
- **A clearer empty window.** With no Projects yet, the window says **Add Your First Project**, with one line on what a Project is and one main **Add Project…** button. Import Project… and Connect Your Agents… are quieter links under it. On macOS, the sidebar `+` now opens the same **New Project…** / **Import Project…** menu as on Linux and Windows.
- **A Get started checklist.** Once you have a Project, a small checklist at the foot of the sidebar tracks adding a Project, adding a Service, starting your first Service and, optionally, connecting your agents. Rows tick from what you've actually done, and an open row takes you to the next step. Close it with ×, and it goes away by itself once everything is ticked.
- **Connect your agents no longer opens by itself.** It's offered from the checklist, and it's still in Settings › Agents, the command palette and the empty window.
- **Nothing changes if you already use localhost.** If you already have Projects, or you've seen the agents sheet before, you won't see the welcome or the checklist.
- The docs now describe the first run, Compose import grouping, Run before and the Python environment field.
