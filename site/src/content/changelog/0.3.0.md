- **The `localhost` command comes with the app.** The macOS app, the Windows installer and the Linux packages now include it, always the same version as the app, and it updates with it: no Rust or `cargo install` needed. The `.deb` and `.rpm` install it as `/usr/bin/localhost`; elsewhere **Settings → Agents → Add to PATH** puts it on your PATH for the terminal, and **Remove from PATH** undoes it. See [The command line](/docs/cli).
- **Connect your agents.** A new screen connects Claude Code, Cursor and Codex in one click: it adds the `localhost` MCP server, pointed at the command inside the app, to the configuration file each one documents, and installs the [localhost-mcp skill](/docs/skills) where each reads skills. **What changes** shows the file and the exact entry before you click; only localhost's own entry changes, each file is backed up before the first change, and **Disconnect** removes only what localhost added. With Claude Code installed, it goes through `claude mcp add-json`; Cursor reuses the skill Claude Code or Codex already has instead of a second copy. See [Connect from the app](/docs/mcp#connect-from-the-app).
- **Find it anywhere.** It opens by itself once, the first time you start this version, and then lives in **Settings → Agents**, the command palette (**Connect Agents…**), the empty window before you add a Project and, on macOS, the localhost menu.
- **Agents that run another `localhost`**, such as one built into `~/.cargo/bin`, or one that's gone because the app moved, show **Update**, which points them at the app's command and keeps the rest of their entry. A command from 0.2.0 can't reach this version's background core: update it there, or reconnect.
- **Updates ask about agents too.** **Restart to Update** lists the running Services and how many agents are connected ("Stop 2 services and disconnect 1 agent and update?"), then stops the Services and disconnects the agents, so the update can replace the command they run. Start a new session in each agent afterwards. See [Updates](/docs/updates).
