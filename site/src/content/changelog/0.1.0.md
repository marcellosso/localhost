The first version of localhost: a native SwiftUI app for macOS, and one app for Linux and Windows, all on one Rust core.

- **Projects and Services**: one command line, working directory and environment per Service, run in your login shell (`cmd.exe` on Windows). Start, stop and restart one Service, or Start All / Stop All in dependency order.
- **Ports**: a Service is Running once its Port accepts connections. A taken port says who holds it, and a Service can move to the next free one for a Run. The Ports view lists every Listener on the machine.
- **Environment**: Project and Service variables, Environment Profiles and Secrets in the system's secret store. “Restart to apply” when a running Service's configuration changes.
- **Logs**: each Service's output with colours, the merged All services view, filter and clear, smooth with very chatty Services.
- **Stats**: a running Service's CPU and memory, sampled only while its popover is open.
- **Suggestions**: Add Project scans the folder for Node scripts, Compose services, Python apps and Cargo binaries, for you to review.
- **Project files**: export a Project to YAML and import it again.
- **Keyboard and accessibility**: the command palette on ⌘K and Ctrl+K, a shortcut for every action, a Keyboard Shortcuts sheet on ⌘/ and Ctrl+/, screen readers, Reduce Motion and Reduce Transparency.
- **The menu bar companion and the tray**, and Orphans offered to stop after a crash.
- **Linux**: packaged as `.deb`, `.rpm` and AppImage.
- **Windows**: a per-user installer. Services run with your user environment read fresh at each start, inside a Job Object, and stop with Ctrl-Break.
- **WSL**: a Project can run inside a WSL distro, through a small `localhostd` the app copies into it. Commands, detection and the Ports view run in the distro.
- **The `localhost` command**, on the same core and data: `projects`, `status`, `logs` and `up`.
