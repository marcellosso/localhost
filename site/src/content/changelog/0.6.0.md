title: Manage a connected Machine's Projects from this app
date: 2026-11-14
released: false

- **Manage a connected Machine's Projects.** You can now add, import, edit, delete and favourite Projects on a connected Machine, just as you do on this computer. That includes editing Services and environment Profiles. Both apps have it.
- **A folder picker that browses the Machine.** Add Project… and Import Project… open a picker that lists folders on the Machine, starting at its home. You can type a path, follow the breadcrumb, go Up or Home, and show hidden folders. Import looks for `.yaml` / `.yml` Project files. Scanning and Suggestions run on the Machine, so they see its `package.json`, Compose files and so on.
- **Secrets stay on the Machine.** Values you type in an editor go over the existing connection and are written only to the Machine's secret store. Nothing of a Machine's Projects is kept on this computer.
- **Older Machines stay view-and-run.** If the Machine is running an older localhost, you can still see its Projects and start and stop Services. Managing them asks you to update localhost on that Machine. Both computers need to be on this release to manage Projects over the connection.
- The docs now describe managing a Machine's Projects.
