---
version: 0.5.2
title: Merge Suggestions and start after another when you add a Project
date: 2026-11-09
released: true
---

- **Compose files become one Infra Service.** A Project with a Compose file that has two or more services now suggests a single **Infra** Service that runs `docker compose up`, checked by default. The individual containers stay available under **N more found**, so you can still add them one by one if you want.
- **Merge Suggestions in the review.** Select a few detected Services and merge them into one, with a name and command you edit. Useful when Postgres and Temporal should be one `docker compose up`, or when a README's steps belong in a single Service.
- **Starts after, already in the review.** Each Suggestion can start after another from the same import, or after a Service the Project already has, so the API waits for Infra without opening Edit Service afterwards.
- **Re-scan keeps your edits.** Scanning again no longer changes Services you already have, and it no longer offers containers that a `docker compose up` Service already covers.
