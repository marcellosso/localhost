title: Anonymous usage data, on by default and easy to turn off
date: 2026-11-09
released: true
---

- **Anonymous usage data, so we can see retention.** The macOS, Linux and Windows apps send two events, `app_first_open` and `app_opened`, to a PostHog project kept apart from the website's. Each event carries only version, OS, architecture, install channel and an anonymous id: no paths, Project or Service names, commands or logs. The `localhost` command and `localhostd` send nothing. See [Privacy](/privacy) and [Analytics](https://github.com/marcellosso/localhost/blob/main/docs/analytics.md).
- **On by default, with a clear way out.** The first open says so once at the foot of the sidebar. Settings › General has **Share anonymous usage data**, and `DO_NOT_TRACK=1` or `LOCALHOST_TELEMETRY=0` turns it off for that session. Debug builds and CI never send.
- **The website no longer autocaptures.** It still records page views and the explicit download and install clicks; the privacy page is linked from the footer.
