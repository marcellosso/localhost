- **Agents add, edit and remove Projects and Services.** `localhost mcp` has six new tools, 15 in all: `create_project`, `update_project`, `delete_project`, `create_service`, `update_service` and `delete_service`. Each change is checked as the app's editors check it (Keys, ports, URLs, working directories, Dependency cycles) and shows in the open app at once, without a restart. Removing needs `confirm: true`, stops what is running first and never touches a Project's folder. Agents set plain variables only, and every Secret stays as it was. A command is stored as given, never run when it's added. See [Tools](/docs/mcp#tools).
- **`localhost mcp --read-only`** leaves those six tools out: the agent can still list, start, stop and inspect. **Settings → Agents** shows a read-only server as connected, and **Update** keeps it read-only. See [Read-only](/docs/mcp#read-only).
- **Connect your agents from a terminal.** With the app installed, `npx @getlocalhost/cli mcp install` writes what **Connect** writes for Claude Code, Cursor and Codex, and Claude Desktop's `claude_desktop_config.json` too, on macOS and Windows. `mcp uninstall` removes it, `mcp status` shows where each agent stands, `--client` picks one, `--read-only` sets up a read-only server and `--dry-run` prints the diff instead. Without the app, it changes nothing and says how to install it. See [Connect from a terminal](/docs/mcp#connect-from-a-terminal).
- **`npx -y @getlocalhost/cli mcp serve`** runs the server from any MCP client's configuration: it finds the command that comes with the app and runs `localhost mcp`, so the same `command` and `args` work in every client and on every OS. See [With npx](/docs/mcp#with-npx).
- **Install with Homebrew on macOS**: `brew install --cask marcellosso/tap/localhost` installs the app and links its `localhost` command into Homebrew's `bin`. The app still updates itself. See [Install](/docs/install#homebrew-macos).
