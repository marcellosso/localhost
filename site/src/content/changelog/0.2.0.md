- **`localhost mcp`**: a Model Context Protocol server for Cursor, Claude Code and other coding agents. They list Projects and Services, start and stop them (one Service or Start All), and read status, logs and ports, instead of starting dev servers in a shell you can't see. The Services an agent starts stop when it disconnects, and it never starts a second copy of one the app runs. See [Coding agents (MCP)](/docs/mcp).
- **An agent skill**, `skills/localhost-mcp/SKILL.md`, that teaches agents to use it: Services through localhost rather than a shell, `status` before saying anything runs, `logs` and `ports` when something fails.
