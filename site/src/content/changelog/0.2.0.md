- **`localhost mcp`**: a Model Context Protocol server for Cursor, Claude Code and other coding agents. They list Projects and Services, start and stop them (one Service or Start All), and read status, logs and ports, instead of starting dev servers in a shell you can't see. The Services an agent starts stop when it disconnects, unless the app is open, and it never starts a second copy of one a `localhost up` runs. See [Coding agents (MCP)](/docs/mcp).
- **The app and agents share their Services.** On macOS, Linux and Windows, the app and `localhost mcp` drive one localhost core in the background (on Windows, for Projects on Windows itself): a Service an agent starts is Running in the app, with its logs, and one you start in the app is running for the agent. A stop from either stops the same Run. When an agent disconnects, the Services it started keep running if the app is open. See [The background core](/docs/mcp#the-background-core).
- **An agent skill**, `skills/localhost-mcp/SKILL.md`, that teaches agents to use it: Services through localhost rather than a shell, `status` before saying anything runs, `logs` and `ports` when something fails.
- **Updates in the app.** localhost checks for a new version at launch and every 6 hours, and shows a notice with the release notes: **Update Now** downloads it in the background, **Restart to Update** installs it, after stopping the running Services (it lists them and asks first). Updates are signed and checked before they install. The AppImage, the Windows installer and the macOS app update themselves; a `.deb` or `.rpm` gets a link to the release. Turn the checks off in Settings. See [Updates](/docs/updates).
