- **The macOS window fits the screen again.** Since 0.5.1, while the anonymous usage data notice was showing, the main window became taller than the screen: it couldn't be resized or moved down, and sheets such as Import Project opened off-screen. The window now resizes normally. If it still opens too tall, double-click its title bar or choose **Window › Zoom** once.
